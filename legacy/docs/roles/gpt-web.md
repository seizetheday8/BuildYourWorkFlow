# gpt-web

> ChatGPT 网页端。当前作为"订阅内推理节点"参与协作。

## 身份

- **ID**：`gpt-web`
- **类型**：网页端
- **模型**：GPT-5.6 Sol

## 能力

> 作用域：本机 / 沙箱 / 对话内 / 无

- **读文件**：沙箱（可读对话附件与沙箱内文件，不读用户本机）
- **写文件**：沙箱（可在沙箱内创建/修改文件，不写用户本机）
- **执行命令**：沙箱（在沙箱/容器内执行，不碰用户本机）
- **联网搜索**：是
- **擅长**：信息检索、分析推理、代码与文档审阅
- **不擅长**：直接控制用户本机、长期驻留自主运行

## 成本

- **计费方式**：订阅内
- **单价（按量时）**：不适用
- **备注**：受订阅额度限制

## 唤醒方式

- **人工触发**：在 ChatGPT 网页端打开对话并发送任务
- **自动触发**：否
- **备注**：可配置定时任务，但普通网页对话不自行唤醒
