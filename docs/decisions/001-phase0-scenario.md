# 001 · Phase 0 场景选择

## 决策

Phase 0 的第一个真实使用场景选 **B**：
**在指定 Go 文件里加一个 HTTP handler。**

## 备选项

**A · 解释代码文件**
- 描述：读一个文件，回答"它做什么"
- 优点：最简，验证 Agent Loop 够用
- 缺点：太简单，不体现工程价值

**B · 在指定 Go 文件里加 HTTP handler（选中）**
- 描述：用户给定文件与需求，Agent 检索 + 生成 + 写回
- 优点：有真实产出、覆盖完整链路、与 Go 学习对齐
- 缺点：Phase 0 稍复杂

**C · 总结 commit**
- 描述：读 git log，总结昨天做了什么
- 优点：贴近日常
- 缺点：不涉及代码生成，Agent 能力验证不充分

## 理由

1. 有真实产出（写出的代码能编译、运行）
2. 覆盖完整链路：检索代码 → 生成代码 → 应用到文件
3. 与用户的 Go 学习进度对齐（每天有真实需求）
4. 与求职叙事（Go + Agent）直接一致
