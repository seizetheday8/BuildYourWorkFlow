# Decisions · 决策记录

> 本目录记录 BYWF 项目的关键决策，用于保持跨时间的一致性。
> 核心原则：**推理归模型，一致性归仓库。**

## 为什么有这份记录

网页端模型"不可控"：新会话会忘记上次决策的推理过程，
可能对同一条规则今天赞同、明天反对。

解法：每次关键决策后写进本目录。
下次模型做新决策前，先读本目录。

## 编号规则

- 3 位数字递增（001、002、...）
- 一旦分配不再重排
- 文件名：`<编号>-<短横线连接的主题>.md`

## 决策文件模板

    # <编号> · <标题>

    ## 决策
    一句话说清选了什么。

    ## 备选项
    当时考虑过的所有选项。

    ## 理由
    为什么选这个，不选其他。

    ## 提出者
    DS / CC / GPT / CX / 用户

    ## 记录 commit
    写进仓库的 commit hash
